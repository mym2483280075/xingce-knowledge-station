一、题型识别与判定

先判准题，再动手找点。判定错，后面全错。

「判定三问」锁定题型

方法
◆ 判定三问
  • 问什么：要我概括的是哪个要素 —— 问题 / 原因 / 影响（作用、危害）/ 对策（做法、措施）/ 成绩 / 特点 / 变化。
  • 问谁：作答范围（“根据给定资料 X”“结合全篇”）与对象主体（哪一主体、哪一领域）。
  • 怎么问：作答要求 —— 字数、条理、语言、身份，是否有“不限于给定资料”等附加条件。

常见设问 → 题型对照

速查
题干常见表述题型要点方向
概括 / 归纳 / 总结 / 概述……的问题概括要点负面事实与表现，按主体或层面归类
……的原因 / 分析……的原因概括原因由结果往回推，找材料里的“因为、由于、根源”
……的作用 / 意义 / 影响概括影响分积极 / 消极，或分对谁的影响
……的做法 / 措施 / 经验概括做法材料里已发生的动作，写“主体＋做了什么”
……的变化 / 前后对比概括变化由……到……，两侧成对写

变形问法：变化 / 特点 / 要求 / 表现

易错
变化＝前后对比，写成“由 A 到 B”，只写单侧等于丢一半分。
特点＝材料里反复出现、可共性的描述，注意与“表现”区分：特点是抽象概括，表现是具体形态。
要求＝材料中的期望性、规范性表述（“应当、需要、必须”引导的），不是已发生的事实。

二、作答流程（四步法）

审题定要素 → 逐段找点 → 分类合并 → 规范书写。

四步作答流程

流程
步骤动作产出常见失误
① 审题用「三问」定要素、范围、要求，在题干上圈出限定词一句话写明“我要找什么”把“原因”看成“问题”，方向直接跑偏
② 找点逐段圈画与要素相关的句子，宁多勿漏材料上成串的标记只看关键词不看句意，漏掉隐性表述
③ 合并同义合并、同层并列、同主体归并若干条要点（分条）直接抄材料原文顺序，条与条交叉重复
④ 书写按字数要求压缩，序号化、要点化最终答案写解释、写感受、超字数

找点：材料标记法与合并三原则

方法
◆ 标记约定（建议固定成肌肉记忆）
  • 单下划线：与要素相关的句子
  • 圈号①②③：第几处要点
  • 方框：出现频率高的关键词
  • 不用多色笔，越简单越不打断阅读
◆ 合并三原则
  • 同义合并：换词不换意，合成一条
  • 同层并列：同一层级的要点并排，不套娃
  • 同主体归并：政府 / 企业 / 社会 / 个人
分类维度三选一即可：主体（谁做的）、层面（制度 / 技术 / 资金 / 人才 / 宣传）、环节（事前 / 事中 / 事后）。同一题内只用一种维度，混用会让条理分丢掉。

字数控制与卷面规范

规范
◆ 要点数估算

预期要点数 ≈ 总字数 ÷ 单点字数。单点一般 20～30 字（含序号），据此先把要点数定下来，再决定合并到什么颗粒度。

◆ 书写三不要
  • 不要抄长句、不要整段照搬材料；
  • 不要写“我认为”“综上所述”这类主观与过渡句；
  • 不要为了凑字加形容词，超字数与欠字数都扣分。
序号形式、标点是否占格、是否可分点，一律以题干要求与本场考试的规定为准，不确定时按考试规定的通用规范书写。

三、采分与复盘

知道分从哪来，才知道复盘要看什么。

评分标准与采分点

评分
采分维度看什么提分动作
要点分（主体）是否踩到材料的核心要点，同义表述可得分把要点找全，宁多勿漏
条理分是否分条、同类是否合并、有无交叉统一分类维度，条与条不重叠
语言分是否简洁规范、有无口语与病句压缩到“主体＋动作＋结果”
踩点给分是评分底线：要点齐全是第一位，形式其次。复盘时先数“丢了几条要点”，再看“条理与语言扣了几分”。

“欢迎宝子们来到我市公安直播间！今天由我来给大家送福利！价值5000 块，九成新华为手机，想偷？三年以下有期徒刑，值不值？”近日，Q市公安“直播带货式”普法爆火。直播中，穿着制服的主播用轻松诙谐的话术开场，一下子就吸引了观众的眼球。这种风趣幽默的“直播带法”吸引了众多网民的围观：“一看就是00 后上岗了。法律知识点就这么水灵灵地进入了我的脑袋。”从热闹程度上看，这种“直播带货式”普法与普通带货直播人气相当，而内容却都与法律有关。比如，主播拿出不少“买家秀”的照片，展示吸食毒品多年后的不同状态：“吸毒时间越长，人越憔悴，吸毒5 年人直接吸没了。”从盗窃到吸毒，主播在直播间里逐一展示这些违法行为的危害。网友纷纷留言：“好，涨知识了！”“太燃了，普法还可以这样搞，真没想到！”话题“Q 市公安的直播间”曾多次冲上热搜榜，据相关数据显示，视频在全网已有2 亿以上播放量。

“见义勇为排排塔”“识诈反诈套圈圈”“食药安全猜猜看”……9 月28 日，在警营开放日活动现场，来自C 市公安机关7 个分局、八大警种的

民警以“流动集市”的形式，设置了反诈、打谣、食品药品安全、交通安全、长江大保护、防范非法集资等宣传防范互动区，向广大群众宣传安全防范常识。“我接到一个电话，听着像外孙的声音，说自己在外面惹事了，要我帮他赔钱。一听就是骗子，之前社区民警在小区广场就跟我们说过。想骗我老太太，可没那么容易！”在反诈中心的摊位前，家住花园新村的钱婆婆和民警分享着自己的经历。“奶奶您真棒！希望您回去跟身边人分享这个故事。”C 市反诈中心民警在为老人的反诈意识点赞的同时，还给她和围观的群众讲解了如何识别“刷单”“投资理财”等多种诈骗手段。

每晚7 点，N 市爱华路一带的烧烤摊、大排档就开始热闹起来。近日，刘先生和朋友相约到爱华路上一家熟悉的烧烤店聚餐，在扫码点餐时，餐桌角上的“温馨提示”桌贴引起了他们的注意。仔细一看，原来是一幅“莫劝酒”漫画，并配有一首小诗：“相聚饮酒莫相劝，醉酒出事同桌担。劝君少喝一杯酒，相互提醒都平安。”刘先生说：“吃烧烤时喜欢喝酒助兴，有时架不住朋友的热情，不知不觉就喝多了。这个‘莫劝酒’桌贴提示很贴心，漫画也很生动，起到了很好的引导和提醒效果。”据了解，“莫劝酒”“莫贪杯”等系列桌贴是当地警方精心设计的一种普法形式。在烧烤店的墙面上，还张贴了印有“饮酒小酌莫贪杯，酒后滋事罚相随”的蓝白色宣传画。“小桌贴和宣传画的效果还是杠杠的，现代人普遍素质高、爱面子，有时默默地提醒比当面劝阻效果要好，现在我们店酗酒闹事的明显少了，生意也好做多了。”店老板张先生由衷地说。

材料二

“您好，我这里是新里程小区。我们计划成立业委会，近期准备召开业主大会，目前还有一些法律知识上的盲点。前不久，收到你们的‘普法清单’，知道你们有这项服务，想邀请你们派人过来指导一下。”H 县司法局收到该小区的请求后，组织宣讲团队进小区，为业主讲解业委会成立的条件、流程，以及民法典中关于物权、侵权责任和业主、业主大会的权利义务等内容。在他们的辅助下，新里程小区业委会顺利成立了，为此，他们专门给县司法局送去了锦旗。

据H 县司法局普法与依法治理股莫股长介绍，新里程小区的普法活动是该县推出的“订单式”普法的一个生动案例。何为“订单式”普法？莫股长解释，“订单式”普法的做法是面向辖区企业、单位以及各镇（街道）、村（社区），统一派发普法清单，群众根据需求“下单”，司法部门再将收集到的“订单”，优化供给、送“法”上门，以群众喜闻乐见的方式，实现普法工作有声有色、有形有效。“有需求，下订单”，已成为该县群众的普遍共识。一年多来，H 县司法局共开展“订单式”普法活动近30 场次，派发宣传资料5000 多份，惠及群众近万人次。

“大家好，欢迎来到‘小叽说法’”。下面我给大家宣讲未成年人保护法和校园安全等知识。”日前，G 县普法宣传大使“小叽”刚一现身“法治校园行”现场，便受到了县实验小学3000 多名师生的欢迎。活动中，除了活泼可爱的“小叽”人偶参与互动外，还有丰富有趣的“小叽说法”系列漫画、接地气的动漫微视频以及多款普法小游戏，一条条枯燥的法律条

文贯穿于生动好玩的宣传产品中，师生们学得不亦乐乎。

“‘小叽说法’是我局倾力打造的具有地方特色的动漫普法项目，它创立于2016 年。”G 县司法局普法与依法治理股陈股长说，为打造“小叽说法”这一品牌，该局特地采用叽叽喳喳的小黄鸡为设计原型，以生动活泼的形象、诙谐幽默的语言和深入浅出的表达方式，引导群众自觉守法、遇事找法、解决问题靠法。

为扩大“小叽说法”品牌的辐射力、影响力，8 年来，G 县司法局持续提升品牌热度，相继推出系列法治动画10 余部、漫画40 余期，制作“小叽”生活用品、玩偶、摆件等衍生品多达20 余类，累计向群众派送近10万个。该品牌多次获得国家和省级普法宣传表彰。

一、整体宏观逻辑：“要求-供给-输出”的闭环对应

1. 题目逻辑：核心指令是“归纳概括各地花式普法的做法+成效”，限定了答案必须包含“主体+核心做法+具体举措+实际效果”四个要素，且要求“全面、准确”，决定了答案采用“并列式结构”（各地做法独立无主次），同时需严格遵循材料顺序避免遗漏要点。

2. 材料逻辑：整体为“总-分”结构（首段“普法打开方式越来越潮”总领全文），三个材料按“普法创新维度”划分成三个并列的案例群，每个案例群内部又包含2-3个独立的地方案例，所有案例均遵循“做法先行+成效跟进”的统一内部逻辑。

3. 答案逻辑：完全匹配题目要求和材料结构，采用“材料顺序+单案例并列”的结构，每个要点精准对应一个地方案例，且每个要点内部严格复刻材料“做法+成效”的逻辑链条。

二、材料内部的逻辑关系

（一）材料间的逻辑：三个维度的递进式创新

三个材料并非简单堆砌案例，而是从“形式创新”→“供给创新”→“文化融合创新”三个层次递进，展现普法创新的深度和广度：

• 材料1：场景化趣味形式创新（线上直播+线下集市+餐饮场景），解决“普法没人看、听不懂”的基础问题

• 材料2：精准化供给模式创新（订单式按需普法+IP品牌化长效普法），解决“普法大水漫灌、效果不持久”的问题

• 材料3：本土化文化融合创新（传统评弹+真实案例），解决“普法脱离群众、缺乏地域亲和力”的问题

（二）单个材料内部的逻辑

1. 材料1（3个案例）：“线上-线下-日常场景”的空间并列逻辑

◦Q市：线上新媒体场景（直播平台）

◦C市：线下集中活动场景（警营开放日）

◦N市：日常消费场景（烧烤店）

◦每个案例内部：“具体做法描述→群众/商家反馈→数据/事实成效”的顺承逻辑

2. 材料2（2个案例）：“精准供给-品牌长效”的时间并列逻辑

◦H县：短期精准响应（订单式，解决即时法律需求）

◦每个案例内部：“典型案例引入→核心模式定义→数据成效总结”的递进逻辑

（一）答案各要点（自然段）之间的逻辑
