一、审题立意

立意定生死：偏题的文章，结构再漂亮也是三类文。

审题三步

流程
步骤动作产出
① 圈关键词把题干中的名词、关系词、限定词全圈出来（尤其“结合”“围绕”“以……为主题”）题干要素表
② 定主题与角度确定主题词，再从材料里找与之相关的最强逻辑（是什么 / 为什么 / 怎么办）一句话主题
③ 提炼总论点把主题写成一句带判断的句子，句子要有态度总论点
总论点必须能从材料中找到支撑。脱离材料的“升华”＝偏题。

分论点从哪里来

方法
◆ 来源一：题干给定

题干中若出现并列短语或递进关系，分论点通常直接对应这几个层次。

◆ 来源二：材料逻辑

材料若按“问题—原因—对策”或“主体分述”展开，分论点顺其结构走最稳。

◆ 来源三：主题拆解（通用三问）

是什么（内涵 / 意义）· 为什么（重要性 / 必要性）· 怎么办（路径 / 举措）。三问任选组合成 3 个分论点，是最不容易出错的一档。

分论点之间必须并列或递进，不能交叉重叠。写成“A 很重要、B 很重要、A 也很重要”就是结构失分。

二、结构框架与写法

结构范式：总—分—总

框架
段落任务篇幅经验值
开头段引题 + 亮总论点占全文 15% 左右
分论点段 ×3每段一个分论点，段首即论点句，随后论证每段占 20%～22%
结尾段回扣总论点 + 升华收束占 10%～15%
四段式（2 个分论点）与五段式（3 个分论点）都可以，关键在分论点覆盖完整、不重复。

开头 / 分论点 / 结尾写法

表达
◆ 开头：三步定型

引出现象或背景 → 一句过渡 → 亮出总论点。开头段里必须有一句可直接抄出来的总论点句。

◆ 分论点段：四件套

论点句（段首）→ 解释一句 → 举例或对比 → 回扣论点一句。四件套齐全，段落就不会显得空。

◆ 结尾：两件事

回扣主题 + 适度升华。不要引入新论点，不要写成口号堆叠。

论证方法与素材运用

方法
方法怎么用适用
举例论证材料中的案例优先，其次才是通用素材几乎所有分论点
对比论证正反两面各举一例，突出论点谈意义、谈危害
引用论证引用材料中的政策表述或权威论述开头、结尾
因果论证讲清“为什么会这样”谈原因、谈必然性
素材优先级：给定材料 > 通用积累。堆砌与材料无关的名人名言，属于典型的“有文采没内容”。

三、采分与复盘

评分标准与采分点

评分
维度评分关注点提分动作
立意是否贴合材料与题干，有无偏题、跑题写前用一句话复述总论点
结构分论点是否清晰、并列或递进、覆盖完整先列提纲再动笔
论证论据是否来自材料、是否有分析每段保证“例＋理”两句
语言与卷面表达是否规范、字数是否达标、字迹是否清晰留 3～5 分钟检查
大作文最大的两类失分：偏题（立意错）与分论点重复（结构乱），都不是靠文采能救回来的。
