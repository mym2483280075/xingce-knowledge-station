一、流程总表

一句话：政治＋常识 → 资料分析 → 判断推理 → 言语理解 → 数量关系 → 收尾回补

120 分钟时间轴

核心
「应到节点」是最晚节点：到点就走；用时含本块涂卡。
应到节点模块（题量 / 分值）用时块内动作
0:14政治＋常识（35 题 / 25 分）14 分政治 ≤35s/题、常识 ≤30s/题；不会就蒙、标 △；做完立即涂卡
0:41资料分析（20 题 / 18 分）27 分四篇先图表材料、后文字材料；先读题干圈「时间＋指标」再回材料；综合分析题放每篇最后；单题 90s 超时跳
1:12判断推理（35 题 / 27 分）31 分类比 2.5 分 → 图形 9 分 → 定义 8 分 → 逻辑 11 分；图形 30s 无思路先跳、60s 强制跳
1:38言语理解（30 题 / 21 分）26 分逻辑填空先语境后选项（≤40s）；片段阅读先问题后文段（≤50s）；只改明确错误的答案
1:47数量关系（10 题 / 9 分）9 分30s 扫全卷 → 挑 4~5 道会做的（工程 / 利润 / 几何 / 和差倍比 / 容斥）→ 其余统一蒙
2:00收尾13 分核对涂卡（防串行 / 漏涂）→ 回补标记题（资料 ＞ 图形 ＞ 言语，只花 30s 能定的）；数量不回补
任何一块超出应到节点 3 分钟，立即熔断进入跳题模式（见 2.1）。若你考副省级卷（多出的 5 题在数量），数量块加 2 分钟、收尾压到 11 分钟，顺序不变。

顺序的三条逻辑

依据
  1. 资料第二棒：全卷第二高分值、最吃脑力，也是最大波动口（六期 40%→55%→65%→80%→45%→65%）——趁清醒＋固定动作做，整套流程的核心是保住资料的 27 分钟。
  2. 判断第三棒：类比 / 逻辑 / 定义是得分发动机（模考六 5/5、10/10、8/10，三块高于班均 +3.68 分），放中段靠技巧落袋；图形在这个块里单给 9 分钟「固定盒子」，不吃定义与逻辑的时间。
  3. 言语第四棒、数量最后：言语靠节奏不靠爆发（六期 57%～87% 波动）；数量单题最耗时、命中率最低（六期 10%～30%），9 分钟只挑题、其余统一蒙，时间不亏。

二、考场纪律

超时即跳 · 熔断 · 分块涂卡 · 一次定答案

四条纪律

纪律
  1. 超时即跳——单题超过上限（见 2.2）就圈起来、先填一个答案，绝不留空。
  2. 熔断——任何一块超出应到节点 3 分钟，立即进入跳题模式：只做一眼会的、其余蒙，按时进下一块，断掉「一块崩盘带崩全卷」的连锁。
  3. 涂卡分块做——每块涂完数一遍答案个数，不用最后统一涂。
  4. 一次定答案——改答案只在发现明确错误时；犹豫是最大的时间黑洞。

单题上限（跳题线）

速查
模块单题上限说明 / 场内动作
政治理论≤35s会就选、不会就蒙；多个表述题先数「表述正确项」
常识判断≤30s凭第一感觉；排除明显错项就撤
类比推理≤30s先判大类、再判小类
图形推理≤60s30s 无思路先跳，60s 强制跳
定义判断≤50s要素法：主体 / 行为 / 条件 / 结果，逐项比对
逻辑判断≤70s翻译推理直套公式；加强削弱先找论点论据
言语理解≤50s每题最多读两遍；只改明确错的
资料分析≤90s找数 → 列式 → 速算；超时跳、做标记
数量关系≤120s只做「看题能列式」的；其余统一蒙

三、重点模块动作

资料 · 图形 · 数量——三个口子的固定动作

资料分析 · 固定动作

动作
  1. 读题干：圈「时间＋指标」——现期 / 基期、同比 / 环比、单位。
  2. 回材料：按关键词定位数据，注意单位与口径（万吨 / 亿吨、% / 百分点）。
  3. 列式＋速算：先看选项差距定精度——差距大直接估算；差距小用截位直除 / 415 份数 / 假设分配。
  4. 排序：综合分析题放每篇最后；单题 90s 超时跳。
  5. 复盘：每道错题贴四类标签——找数 / 列式 / 计算 / 比较（用来定位六期 40%～80% 大起大落的根因）。
目标：≥16/20（80%）——10月3日上午已打出 16/20。

图形推理 · 固定动作

动作
  • 考场内：30s 无思路先跳、60s 强制跳，绝不恋战——守住的不是图形，是定义与逻辑的时间。
  • 场下练：每天 15 题按规律分块刷——点线面角素 / 对称 / 笔画奇点 / 立体展开；每周末回看一次错题规律小结。
  • 目标：≥6/10（60%）——10月1日上午已打出 7/10；六期一直卡在 40%～50%（班内 84/91），先突破这一档。

数量关系 · 固定动作

动作
  • 考前只固化 5 类必拿题型：工程 / 利润 / 几何 / 和差倍比 / 容斥。
  • 考场 9 分钟：先 30s 扫全卷挑题，只做「看题能列式」的 4~5 道（每题 ≤120s），其余统一蒙同一个选项。
  • 目标：≥4/10（40%）——9月18日已打出 40%；班均约 37%，先站上地板再谈提高。

五、申论时间流程

180 分钟 · 5 题：审题 5 分 → 小题 110 分 → 大作文 60 分 → 收尾 5 分

180 分钟时间轴（5 题）

核心
以国考申论（180 分钟 / 100 分 / 5 题）为例：节点是开考后分钟数，与具体钟点无关；题型顺序按本站申论模考卷式（归纳 → 分析 → 对策 → 应用文 → 大作文）。
应到节点阶段（分值）用时块内动作
0:05填信息＋审全卷5 分先填姓名 / 准考证号；再用 5 分钟把 5 道题的「题型＋作答对象＋材料范围＋字数」标在题本上，材料按题号标段落
0:25归纳概括（10~15 分）20 分5 分钟审题定位 → 12 分钟找点（要点直接用材料规范表述）→ 3 分钟分点成文；字数写到要求的 90%
0:50综合分析（15~20 分）25 分3 分钟定角度（词句理解 / 观点评价）→ 8 分钟理材料逻辑链 → 12 分钟按「是什么—为什么—怎么办」作答 → 2 分钟查逻辑闭环
1:20提出对策（20~25 分）30 分5 分钟锁问题 → 10 分钟提取材料现成对策 → 13 分钟补原创对策（主体＋措施＋效果）→ 2 分钟按「短期 / 长期」分层
1:55应用文 / 公文（20~25 分）35 分6 分钟定文种与格式 → 10 分钟提材料信息 → 17 分钟写全「标题＋称谓＋正文＋落款」→ 2 分钟核格式；格式分一丢就是硬伤
2:55文章写作（35~40 分）60 分10 分钟审题立意 → 15 分钟搭框架（总论点＋3 个分论点＋素材关键词）→ 30 分钟写正文 → 5 分钟查卷面；最迟开考第 120 分钟必须动笔
3:00收尾5 分查题号对应 → 查漏题 → 查作文是否写够 1000 字 → 查涂改；答题卡不留空
两条熔断线：① 开考 80 分钟（表内 1:20）还没做完第二题 → 当前题只写已找到的要点，立即推进；② 开考 120 分钟（表内 2:00）无论小题做到哪，必须开始写大作文——35~40 分的题不能残。小题写不完美只丢几分，作文写不完直接丢一档。
场次总时长缩放（审题＋阅读 / 小题 / 大作文 / 收尾）
国考（5 题）180 分钟审题 5 → 小题 4 道共 110 → 大作文 60 → 收尾 5
省考（4 题）150 分钟审题 5 → 小题 3 道共 75 → 大作文 60 → 收尾 10

申论四条纪律

纪律
  1. 先审题、后读材料——5 道题的「作答对象 / 范围 / 字数 / 文体」先标清；读材料时按题号做标记（第 3 段 → 第 2 题），一遍读完直接作答，不回头重读。
  2. 要点优先于文采——小题按点给分：先写要点词、再补连接句；材料里的规范表述直接抄，改写只做在口语化表述上。
  3. 一次成文不回改——只列关键词提纲，不写整段草稿；错字划一道即可，不涂黑、不大段重写。
  4. 作文保底 60 分钟——小题到点就收，绝不用作文的时间补小题；小题用时 ≈ 分值 × 1.5（10 分题 15~20 分钟），大作文按 ≥1.7 分钟 / 分单算（40 分 = 60 分钟起）。

开考前后六个动作

动作
  1. 入场：准考证＋身份证；黑色签字笔 ≥2 支、2B 铅笔、橡皮、手表（无存储功能）；手机按监考要求关机存放。
  2. 发卷后未开考：先填姓名 / 准考证号，检查题本页数与题号；不做题、不翻页（以监考指令为准）。
  3. 开考铃响 5 分钟内：审全卷 5 题，把题型与材料范围标记完，再动笔写第一题。
  4. 推进中：每做完一题核对一次题号与答题区域；大题之间留 1 行空隙，方便回补要点。
  5. 监考报「最后 15 分钟」：作文没写到 800 字先补字数；再查题号、漏题、空行。
  6. 交卷前 5 分钟：只做三件事——查题号、查空题、查作文结尾；不再改小题内容。
答题卡一律不留空：小题实在不会，也要按材料抄要点凑满——申论空题 = 0 分，凑满至少拿要点分。

申论部分依据

依据
  • 时长与题量：国考申论 180 分钟 / 100 分 / 5 题（华图教育《国考的行测和申论答题时间分别多久》2025-11-28；百度百科「申论」词条）。
  • 分题型时间：归纳 20 / 综合 25 / 对策 30 / 应用文 35 / 大作文 60 / 机动 10（搜狐《备考指南｜申论时间怎么分配》2025-11-26；知乎「国考申论五道题三个小时怎么分配」同口径：归纳 ≤25、对策 25~30、综合 ≤30、大作文 60~70）。
  • 审题＋阅读口径：华图建议「5 分钟审题＋25~30 分钟读材料」，另有公开方案建议阅读 30~40 分钟；本卡采用「先审题、边读边做」合并口径——每题内的审题与定位时间计入该题，避免重复计时。
  • 版本：v1 · 2026-10-05——先按此流程跑 2~3 套申论模考，再按实际用时标定；考场不临时改节奏。
