四条诊断 结论先看这里

① 五期最高分，却是名次原地踏步：61.7（72 / 94、年级 419）

五期整卷 49.2 → 60.2 → 60.8 → 57.9 → 61.7，绝对分第一次站上 61；但名次几乎没动（年级 422 → 419，班内 64 / 93 → 72 / 94）。原因在班均：本场全班平均 66.07、中位数 67.15，都比上一场（61.53 / 62.0）高出一大截；与班均差一路走来 −11.97 → −1.81 → −0.45 → −3.63 → −4.37。同分段（60.7～62.7）只有 4 人、段均 62.0——本场 60 分以上有 74 / 94 人，分数是涨了，但优势没建立起来。

② 资料分析从五期最强变成最大失分口：80% → 45%

9 / 20（45%、失 9.9 分、班内 90 / 94、−5.51）。五期曲线 40% → 55% → 65% → 80% → 45%：上一场刚创的新高整段回吐，且比同分段段均（9.68）还低 1.6 分、比班中位（13.95）低 5.85 分。资料一向是四期连升的「最稳一块」，本场变成全卷最大单科缺口——11 道错题折 9.9 分，比数量的 8.1 分还多。

③ 数量关系 1 / 10（10%），五期首次探到 10%

失 8.1 分、班内 82 / 94（−2.20）。五期曲线 20% → 30% → 20% → 20% → 10%，从未真正打开；班均也只有 3.10 / 9（34%），说明这块是全班的地板——但我在全班地板上仍低 2.2 分，等于每场白送 2 分以上的差距。资料 + 数量合计失 18 分，占全卷失分（38.3 分）的 47%。

④ 亮点集中在言语与判断：言语五期最高，逻辑 / 定义 / 政治 / 常识高于班均

言语 20.8 / 24（87%、班内 12 / 94、+2.95）——五期曲线 57% → 80% → 67% → 57% → 87%，第一次把言语变成得分项；逻辑 7.2 / 9（80%、30 / 94、+0.58，比上场回升 20pp）；定义 6.4 / 8（80%、39 / 94、−0.04 基本持平班均）；政治 4.8 / 8（60%、19 / 94、+0.66，五期连升 45% → 30% → 50% → 55% → 60%）；常识 60%（30 / 94、+0.57）持平。图形推理 50%（+10pp、59 / 94、−0.96）止住四连跌、但仍未回到班均。四块优势合计 +4.76 分。

下一阶段补什么 按性价比排序

  1. 资料分析（第一优先，可捞约 5.5 分）：45%、班内 90 / 94，11 道错题是五期最多的单科失分（9.9 分）。上一场刚打出 80%，说明方法与手感都在，本场更像执行崩盘——先把本卷四组材料限时重做（20 题 25 分钟），逐题标注错因类型（找数 / 列式 / 计算 / 比较大小），恢复「先读题、再定位、后列式」的顺序；之后每天 1 组（5 题）保温。
  2. 数量关系（第二优先，可捞约 2.2 分）：1 / 10（10%），五期最低，与班均的差距（−2.2）比图形还大。不追全覆盖，只锁工程、利润、几何、和差倍比、容斥五类必拿题型，其余题统一蒙一个选项；目标先到班均 3.1 分（34%），把时间留给资料与图形。
  3. 图形推理（回升待巩固，可捞约 1 分）：50%（+10pp）止住四连跌，但仍在班均线下 0.96 分（59 / 94）。每天 15 题按规律分块刷（点线面角素、对称、笔画奇点、立体展开），每周末回看一次错题规律小结。
  4. 类比推理 / 定义判断（保手感，不追加）：两块 60% / 80%，−0.43 / −0.04，都贴在班均线上——每周 20 题类比、每天 10 题定义，维持「题干关系层级」与「要件逐项比对」的固定动作即可。
  5. 保温项（只回刷错题，不加量）：言语理解（87%、五期最高）、逻辑判断（80%）、政治理论（60%、五期连升）、常识判断（60%）——四块合计高于班均 +4.76 分，是当前的基本盘；每周各 20～30 题保持，把大块时间让给资料与数量。
目标换算：资料 8.1 → 13.6（+5.51 分）+ 数量 0.9 → 3.1（+2.20 分），两项合计约 +7.7 分，总分约 69.4——班内约 37 / 94、年级约 225；再把图形补到班均，总分约 70.4、年级约 187。
