四条诊断 结论先看这里

① 三连涨之后第一次回撤：57.9 分（班内 64 / 93、年级 422）

10月1日上午 49.2（82 / 92、512）→ 下午 60.2（59 / 96、341）→ 模考三 60.8（55 / 98、304）→ 模考四 57.9（64 / 93、422）。本场卷面难度与上一场基本一致（班均 61.25 → 61.53、班内最高 79.7 → 79.1、标准差 8.5），所以这 −2.9 分不是卷子变难，而是自己的失分抬头：与班均差从 −0.45 扩大到 −3.63，折算到「同分段」看，56.9～58.9 这一段就有 12 人，我已经滑到班里后 1/3（超过班内 30% 的人）。

② 资料分析是四期最亮的一条线：40% → 55% → 65% → 80%

资料 14.4 / 18（80%、班内 39 / 93、+0.75），四期连续上升，且与同分段段均（13.05）相比高 1.35 分，是当前最稳的一块。常识判断 5.4 / 9（60%、29 / 93、+0.77）与政治理论 8.8 / 16（55%、38 / 93、+0.35）也都在班均之上——政治还创下四期最高（45% → 30% → 50% → 55%）。三块优势合计 +1.87 分。

③ 图形推理连续四场回落，是本期最大失分口

图形 2.8 / 7（40%，班内 85 / 93，−2.20）：70% → 60% → 50% → 40%，四期每期掉 10pp，本场 10 题只对 4 道，6 道错题（77 / 78 / 79 / 80 / 82 / 84）覆盖位置规律、分组分类与立体展开。数量关系 1.8 / 9（20%，68 / 93，−1.66）又是 66～75 整块蒙 C，8 错 2 蒙对。两块合计 −3.86 分，比全卷净缺口（−3.63）还大——也就是说，其余七块整体是在帮这两块填坑。

④ 高位模块集体回吐：类比 −40pp、逻辑 −20pp、言语 −10pp

类比推理从上一场的满分（并列班内第 1）掉到 3 / 5（60%、−0.29），逻辑判断从 80% 掉到 60%（−0.69），言语理解从 67% 掉到 57%（基本盘持平，−0.04）。三块合计 −1.02 分。本场回升的是定义判断（60% → 70%，+0.61，班内 57 / 93），但还没回到班均之上。好消息与坏消息各一半：优势块在变宽（资料、政治、常识），但靠单场超常撑起来的块（类比满分、逻辑 80%）没有留住。

下一阶段补什么 按性价比排序

  1. 图形推理（第一优先，可捞约 2.2 分）：40%、班内 85 / 93，且是连续四场回落的一块（70% → 60% → 50% → 40%），四期唯一没有反弹过的模块。6 道错题（77 / 78 / 79 / 80 / 82 / 84）覆盖位置规律、分组分类与立体展开。每天 15 题按规律分块刷（点线面角素、对称、笔画奇点、展开图），考场分 2～3 次做，避免连续卡壳——这一块的投入产出比现在全卷最高。
  2. 数量关系（只锁 5 类必拿，可捞约 1.6 分）：66～75 整块蒙 C 只对 2 题，连续三场停在 20% 上下，没有回报。不追全覆盖，只锁工程、利润、几何、和差倍比、容斥五类；其余题统一蒙一个选项，把时间留给图形与资料。班均也只有 3.47 / 9（39%），目标定在班均即可。
  3. 逻辑判断 + 定义判断（合计可捞约 1.3 分）：逻辑从 80% 回到 60% —— 把 101 / 103 / 104 / 105 四道按「翻译推理 / 加强削弱」归类复盘，每天 5 题保持；定义 70%、3 道错题（86 / 92 / 95）固定动作仍是先圈「主体 / 对象 / 方式 / 目的」再逐项比对，每天 10 题。
  4. 类比推理（保手感，不追加）：从满分回落到 60%（96 / 100 两道错），属于正常波动；每周 20 题保持区分「题干关系层级」的手感即可，不必加大投入。
  5. 言语理解（保温 + 复盘）：57%、与班均持平（−0.04）；13 道错题里 8 道在逻辑填空与语句表达。每天 10 题逻辑填空（词义辨析 + 语境对应），每周 2 篇片段阅读保持手感。
  6. 保温项（只回刷错题，不加量）：资料分析（四期连升、80%）、政治理论（四期最高、55%）、常识判断（高于班均）——每周各 20～30 题保持手感，把大块时间让给图形与数量。
目标换算：图形 2.8 → 5.0（+2.20 分）+ 数量 1.8 → 3.5（+1.66 分），两项合计约 +3.9 分，总分约 61.8——班内约 48 / 93、年级约 304（回到上一场水平）。再把逻辑、定义补到班均，总分约 63.1、年级约 268。
