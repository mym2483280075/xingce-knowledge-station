四条诊断 结论先看这里

① 六期最强，名次第一次大步前进：66.0（42 / 91、年级 244）

六期整卷 49.2 → 60.2 → 60.8 → 57.9 → 61.7 → 66.0；其中四场 130 题同配分的卷子是 49.2 → 60.8 → 57.9 → 66.0。年级 419 → 244（−175 名），首次进入年级前 250；班内 72 / 94 → 42 / 91，第一次超过班里一半同学（52.7%）。更关键的是位置：与班均差 −4.37 → +1.29，六期第一次转正——分数涨、位置也真涨。同分段（65.0～67.0）7 人、段均 66.16；本场 60 分以上 69 / 91、70 分以上 24 / 91。

② 判断推理是发动机：类比、逻辑两块满分，定义班内第 2

类比 4.0 / 4（100%、班内并列第 1、比上一场 +40pp）；逻辑 8.0 / 8（100%、班内并列第 1、+20pp）；定义 6.4 / 8（80%、班内 2 / 91、高于班均 +1.56）。三块合计高于班均 +3.68 分，是全卷位置前进的第一功臣。再加常识 5.4 / 9（60%、班内 9 / 91、+1.73）——判断推理四块里三块 + 常识，构成了本场的「得分底盘」。

③ 失分口收窄到三块，但都还在班均线下：资料 −2.22、图形 −1.85、数量 −0.66

资料分析 11.7 / 18（65%、班内 68 / 91）比上一场 +20pp、多对 4 题，但仍是最大缺口；图形推理 3.5 / 7（50%、班内 84 / 91）已连续四场停在 40%～50%；数量关系 2.7 / 9（30%、六期最高）仍未到班均（3.36）。三块合计缺口 4.73 分——对比上一场三块缺口 8.67 分，收窄了 3.94 分，这正是本场超额进步的主要来源；但三块合计仍失 16.1 分，占全卷失分 34.0 分的 47%。

④ 两个回落信号：言语 87% → 70%，政治 / 常识持平

言语理解 14.7 / 21（70%、班内 45 / 91）比上一场（87%、五期最高）回落 −17pp，刚好贴在班均线上（+0.02），是六期对照里唯一明显回落的一块；政治理论 9.6 / 16（60%）与常识 60% 都持平（政治五期连升后首次停涨，但两块仍都高于班均 +0.58 / +1.73）。判断推理把分数顶上来之后，言语别掉队、政治常识再加一点，就是下一场守住 66+ 的关键。

下一阶段补什么 按性价比排序

  1. 资料分析（第一优先，可捞约 2.2 分）：13 / 20（65%、班内 68 / 91）。六期曲线 40% → 55% → 65% → 80% → 45% → 65% 大起大落，说明方法与手感都在、稳定性不够——本卷四组材料限时重做（20 题 25 分钟），逐题标注错因类型（找数 / 列式 / 计算 / 比较大小），之后每天 1 组（5 题）保温。
  2. 图形推理（第二优先，可捞约 1.85 分）：5 / 10（50%、班内 84 / 91），六期 70% → 60% → 50% → 40% → 50% → 50%，一直没有突破。每天 15 题按规律分块刷（点线面角素、对称、笔画奇点、立体展开），每周末回看一次错题规律小结；目标是先把正确率抬到 70%（7 / 10）。
  3. 数量关系（第三优先，可捞约 0.7 分）：3 / 10（30%、六期最高），班均 3.36 / 9（37%）——这块是全班地板，先站上地板。只锁工程、利润、几何、和差倍比、容斥五类必拿题型，其余统一蒙一个选项；限时 15 分钟拿稳 4～5 题。
  4. 保基本盘（判断推理 + 常识，不加量）：类比 5 / 5、逻辑 10 / 10、定义 8 / 10（三块合计 +3.68）、常识班内 9 / 91（+1.73）——每周各 20～30 题维持手感，把大块时间让给资料与图形。
  5. 盯回落（言语 + 政治）：言语从 87% 回落到 70%（−17pp、刚好班均线）——用本卷错题回刷找节奏，每周 30 题保持；政治 60%（五期连升后持平、班内 31 / 91），每天 10 题时政 + 错题回看，不让它掉回 50% 区间。
目标换算：资料 11.7 → 13.9（+2.22 分）+ 图形 3.5 → 5.35（+1.85 分），两项合计约 +4.1 分，总分约 70.1——班内约 23 / 91、年级约 117；再把数量补到班均（+0.66），总分约 70.7、年级约 103。
