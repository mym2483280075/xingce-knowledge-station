数据口径与更新 看结论前先读

  • 数据来源：站内各期「成绩分析」页（分数、名次、逐题 / 逐模块明细都在那边）；11月13日申论五题分项由用户提供并与 62.5 正式总分闭合。原始成绩表本地留存、未入站，本页只保留分数与名次，不含姓名与准考证号。
  • 综合口径：综合 = 行测 ＋ 申论，满分 200；单科专场不计综合分；需要与单科比较时用「折合 100 分制」（综合 ÷ 2）。
  • 跨卷可比性：行测 120 题场（卷二 / 模考五 / 9月18日 / 提升卷一）与 130 题场（卷一 / 卷三 / 卷四 / 卷六 / 9月22日 / 模拟卷七 / 提升卷二 / 提升卷四）配分不同，跨卷只比得分率与同场位置；同为 130 题且同配分的卷一 / 卷三 / 卷四 / 卷六 / 模拟卷七 / 提升卷二 / 提升卷四可直比绝对分。申论九期同为 100 分制，跨期只比得分率。
  • 缺失数据：第 1 期（9月7日）、第 4 期（9月24日）成绩表尚未入站，总表留空；补录后按同一张表继续累加，并同步更新上面的三条曲线与结论。
  • 更新方式：每场考完 → 先在当期「成绩分析」写入模块 / 失分 / 下一步 → 回本页在历次总表与对应分科表各加一行（分科表的行带 data-t / data-v，曲线自动跟着变）→ 运行站内刷新脚本重建索引与缓存版本。
